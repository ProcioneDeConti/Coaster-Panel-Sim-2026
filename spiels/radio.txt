# Radio chatter for the Ballin'-Radley emulator (ride operations channel).
#
# Each line is a header '== CLIP ID | SPEAKER ==' followed by what is said.
# - SPEAKER is SUP (ride supervisor) or MAINT (maintenance).
# - The clip id is what the app's RadioDesk asks for; keep ids as they are, edit the words freely.
# - Clips are rendered by tools/spiels/radio.py into app/src/main/assets/radio/ with a two-way radio effect.
# - Lines starting with # are comments.
#
